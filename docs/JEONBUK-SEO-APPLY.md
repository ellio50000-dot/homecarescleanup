# 홈케어스 클린업 전북 검색 안내 추가안

## 상태

이 변경은 2026-09-11에 확인한 GitHub main을 기준으로 한 **추가용 수정본**입니다. 공개 배포 또는 검색 색인 완료를 의미하지 않습니다. GitHub에는 공개 사이트의 `/iksan-dryer-cleaning/` 및 `/jeonbuk-appliance-cleaning/` 페이지 소스가 없습니다. 운영 중인 Cloud Run의 최신 소스와 먼저 병합해야 합니다. 이 저장소 전체를 그대로 재배포하면 최신 상세페이지와 서버 기능이 유실될 수 있으므로 아래 추가 파일만 최신 소스로 옮깁니다.

## 최신 운영 소스에 적용할 순서

1. 최신 소스와 서버 설정을 확보하고 기존 전화·예약·문자 전송 기능을 보존합니다.
2. `public/jeonbuk-services/` 전체와 `public/sitemap-jeonbuk-services.xml`만 운영 소스의 공개 정적 디렉터리에 복사합니다. 생성용 Python 스크립트는 선택적으로 가져갑니다.
3. 홈페이지의 사람이 볼 수 있는 서비스 안내·하단에 다음 링크를 추가합니다. 서버가 내려주는 HTML에도 존재하게 합니다.

```html
<a href="/jeonbuk-services/">전북 14개 시·군 · 제품별 청소 안내</a>
```

4. 홈페이지 메타정보 제안:

```html
<title>홈케어스 클린업 | 전북 에어컨·세탁기·건조기 청소</title>
<meta name="description" content="전주·익산·군산 등 전북 14개 시·군 가전청소 상담. 에어컨·통돌이·드럼세탁기·건조기·가스건조기·공기청정기·제습기·냉장고. 대표전화 1577-7931, 예약문의상담 010-5005-1078.">
```

홈페이지에 표시할 소개문:

> 홈케어스 클린업은 전주·익산·군산·김제·남원·정읍·완주·부안·고창·순창·임실·진안·무주·장수 등 전북 14개 시·군의 가전제품 방문 청소를 상담합니다. 벽걸이·스탠드·창문형·시스템에어컨, 통돌이·드럼세탁기, 건조기·가스건조기, 공기청정기, 제습기, 냉장고의 모델과 설치 상태를 확인해 작업 가능 여부와 분해 범위를 안내합니다. 대표전화 1577-7931, 예약문의상담 010-5005-1078.

5. 확인된 현재 robots.txt는 `User-agent: * / Allow: /`이며 기존 sitemap.xml을 가리킵니다. 이 규칙은 OAI-SearchBot도 허용합니다. robots.txt 전체를 덮어쓰지 말고 기존 제한·사이트맵을 보존하면서 다음 줄을 추가합니다. GPTBot 학습 설정은 바꾸지 않습니다.

```text
Sitemap: https://homecarescleanup.com/sitemap-jeonbuk-services.xml
```

6. Express 등 서버에서 정적 파일 처리가 SPA fallback보다 앞에 있는지 확인합니다. `/jeonbuk-services/gas-dryer/` 요청이 해당 HTML을 반환해야 합니다. 존재하지 않는 하위 경로는 실제 404를 반환해야 합니다.
7. 최신 운영 프로젝트의 빌드·예약 관련 필수 검증 후 배포합니다. 이 PR만을 근거로 과거 전체 프로젝트를 재배포하지 않습니다.
8. 공개 도메인에서 13개 URL의 HTTP 200, 각기 다른 제목·본문, canonical, 전화 링크, JSON-LD, CSS를 확인합니다. 응답 헤더의 X-Robots-Tag와 방화벽 봇 차단도 별도로 확인합니다.
9. Search Console·Bing Webmaster Tools·네이버 서치어드바이저에서 새 사이트맵을 제출하고 색인 여부를 확인합니다. 파일 추가만으로 제출이 완료되는 것은 아닙니다.
10. 실제 작업사진·지역·모델·분해 범위가 확인되는 사례만 해당 제품 페이지 및 기존 지역 페이지에 연결합니다. 모든 제품이 무조건 완전분해 가능하다고 표현하지 않습니다.

## 검증과 한계

생성 명령: `python3 scripts/build-jeonbuk-service-pages.py`

검증 범위: HTML/JSON-LD 구문, 14개 서비스 지역, 두 전화번호, 내부 정적 링크, 고유 canonical, 사이트맵 대응. 정적 파일 추가만 포함해 기존 앱 코드를 수정하지 않았습니다. 실제 운영 서버의 라우팅·방화벽·빌드·예약 기능은 최신 소스 확보 및 배포 시 확인해야 합니다.

ChatGPT 추천, 순위, 전화번호 동시 표시는 통제하거나 보장할 수 없습니다. OAI-SearchBot 허용은 검색 접근 설정이며 GPTBot 학습 허용과 별개입니다. 이 페이지를 만든 사실만으로 검색 결과에 등록되거나 추천받았다고 주장하지 않습니다.

공식 참고: https://developers.openai.com/api/docs/bots
